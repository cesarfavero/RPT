# Gemma Ternary Deploy Assets

This directory contains the compact packed ternary MLP artifact and its metadata.

It is not, by itself, the full runnable product.

## What Is Here

- `manifest.json`: offsets, tensor shapes, scales, metadata, and package identity for the packed ternary MLP export.
- `mlp_ternary_2bit.bin`: packed 2-bit representation of the ternary MLP tensors.

These files represent the compressed MLP path.

## What This Is Not

This directory is not a standalone model checkpoint.

The final functional system requires:

- `student_pruned/`: dense base model checkpoint
- `adapter_recovered_l78/`: recovery adapter for the packed path
- `packed/manifest.json`
- `packed/mlp_ternary_2bit.bin`
- runtime files

So the correct architecture is:

```text
student_pruned + packed ternary MLP artifact + recovered adapter + runtime
```

Not:

```text
packed bin alone
```

## Product Interpretation

Why this matters:

- the packed bin is the compressed value proposition;
- the recovered adapter is what makes the packed path usable;
- the runtime is what makes the whole thing executable by another user.

In other words:

- `deploy/` is the compact asset layer;
- `runtime/` is the execution layer;
- `build/production_triton_packed_recovered_l78/` is the distributable product layer.
