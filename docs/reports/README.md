# Reports and Technical Notes

This folder keeps long-form reports and checklists out of the repository root
while preserving them as part of the public project record.

Some reports are historical snapshots and may mention superseded private or
closed-source planning. The current project policy is defined in
[`../operations/PROJECT_GOVERNANCE.md`](../operations/PROJECT_GOVERNANCE.md).

## Contents

- `RPT_DOCUMENTO_COMPLETO.md`: broader project document.
- `RPT_VALIDACAO_BITNET2B.md`: BitNet validation notes.
- `RPT_9_MODEL_OPTIMIZATION_ROADMAP.md`: model optimization roadmap.
- `SECURITY_AUDIT_2026-04-27.md`: security audit snapshot.
- `TECHNICAL_EXECUTION_CHECKLIST.md`: execution checklist.
